Adventure Game

## 📝 Brief Explanation
 Adventure Game is a text-based RPG built with HTML, CSS, and JavaScript, where players explore different locations, battle monsters, earn gold, and upgrade weapons. The game offers multiple choices, such as visiting a store to buy weapons, entering a cave to fight monsters, or facing the ultimate boss—a dragon! With a dynamic combat system, inventory management, and a hidden Easter Egg mini-game, this project provides an engaging and interactive experience.

## 🎮 How to Play
- Start in the **Town Square**, where you can visit the store, enter the cave, or fight the dragon.
- **Store**: Buy health potions and better weapons.
- **Cave**: Battle monsters to gain experience and gold.
- **Fight Dragon**: Challenge the ultimate boss!
- Make strategic choices using the on-screen buttons.
- Manage your **health**, **gold**, and **inventory** to survive.

## 🛠️ Technologies Used
- **HTML**: Structuring the game interface.
- **CSS**: Styling the game elements.
- **JavaScript**: Implementing game logic and interactions.

## 🚀 Features
- Multiple locations to explore.
- Dynamic inventory and weapon upgrades.
- Randomized combat system with attack and dodge mechanics.
- Secret Easter Egg mini-game!

## 📂 Installation & Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Diyaa2554/Advanterous-game.git
   ```
